# Amazon India Sales Analysis Dashboard | Excel

## Project Overview
The **Amazon India Sales Analysis Dashboard** is an Excel-based data analysis project designed to monitor and analyze Amazon's sales performance.

The main objective is to help management understand business performance through interactive visualizations, key performance indicators (KPIs), and charts.

The dashboard provides insights into sales, profit, products, orders, customer order status, payment methods, fulfilment methods, and geographic performance.

## Problem Statement
The management team needs a simple and easy-to-understand dashboard to monitor overall business performance and support better decision-making.

The dashboard helps identify:
- Overall sales and profit performance.
- Best-performing product categories and products.
- Order delivery, return, and cancellation performance.
- Payment and fulfilment method performance.
- State-wise sales and profit contributions.

## Project Objectives
- Analyze overall sales and profitability.
- Identify high-performing products and categories.
- Monitor order status and revenue loss.
- Understand customer payment preferences.
- Evaluate fulfilment performance.
- Identify top-performing states based on sales and profit.

## Dataset Description
The project uses an Amazon India sales dataset containing 10,000 order records.

Important columns include:
- Order ID
- Order Date
- Product
- Category
- Quantity
- Total Sales (INR)
- Profit (INR)
- Payment Method
- Fulfilment
- Order Status
- Shipping State

1. Download the Excel dashboard file from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the **Dashboard - Final** worksheet.
4. Explore the KPIs and charts to understand business performance.
5. Navigate to **Dashboard Data** to view the supporting analysis.
6. Open **Amazon sales data** to explore the original dataset.
